# 🌿 أكاديمية البيروني — Académie Al-Biruni

منصة تعليمية رقمية للتعليم الإعدادي بالمغرب

## الملفات

| الملف | الوصف |
|-------|-------|
| `index.html` | الصفحة الرئيسية (Landing Page) |
| `dashboard.html` | لوحة تحكم التلميذ |
| `teacher.html` | لوحة تحكم الأستاذ |
| `parent.html` | لوحة تحكم الوالدين |
| `pricing.html` | صفحة الاشتراك والدفع |
| `css/style.css` | تنسيقات الصفحة الرئيسية |
| `js/main.js` | JavaScript التفاعلية |

## كيفية الاستخدام

افتح `index.html` في المتصفح مباشرة، أو ارفع الملفات على أي استضافة.

## Stack المقترح للتطوير الكامل

- **Frontend**: Next.js 14 + TailwindCSS + TypeScript
- **Backend**: NestJS + Node.js
- **Database**: PostgreSQL + Redis
- **Storage**: AWS S3 + Cloudflare Stream
- **Auth**: JWT + OAuth 2.0
- **Payments**: CMI + Stripe
- **Mobile**: React Native
